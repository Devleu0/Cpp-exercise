기본 문법 및 데이터 타입
==============

프로그램을 구성하는 가장 작은 단위인 문법과 데이터를 저장하는 다양한 방식을 알아봅니다. 모든 코드의 기초가 되는 중요한 개념들입니다.

### 주석, 변수, 상수

**주석**은 코드에 대한 설명을, **변수**는 변경 가능한 데이터를, **상수**는 변경할 수 없는 데이터를 저장하는 데 사용됩니다.

    // 변수 선언 및 초기화
    int userAge = 25;
    
    // 상수 선언 (값 변경 불가)
    const double PI = 3.14159;

### 기본 데이터 타입

데이터의 종류를 나타내며, 각 타입마다 메모리 크기와 표현할 수 있는 값의 범위가 다릅니다.

연산자 (Operators)
===============

값을 조작하거나 비교하는 데 사용되는 기호입니다. 연산자를 통해 복잡한 계산과 논리적인 판단을 수행할 수 있습니다.

### 산술, 관계, 논리 연산자

**산술 연산자**는 계산을, **관계 연산자**는 비교를, **논리 연산자**는 여러 조건을 조합하는 데 사용됩니다.

    int a = 10, b = 4;
    // 산술: a % b  // 결과: 2 (나머지)
    // 관계: a > b   // 결과: true (1)
    // 논리: (a > 5) && (b < 5) // 결과: true (1)
    

### 증감, 대입 연산자

**증감 연산자**는 값을 1씩 변경하며, **대입 연산자**는 변수에 값을 할당합니다.

    int x = 5;
    x++; // x는 6이 됨
    
    int z = 10;
    z += 5; // z = z + 5와 동일, z는 15가 됨
    

입출력 스트림 (I/O Stream)
====================

콘솔을 통해 사용자로부터 데이터를 입력받거나 화면에 데이터를 출력하는 기능입니다. 프로그램과 사용자 간의 상호작용을 가능하게 합니다.

### \`std::cout\`과 \`std::cin\`

\`iostream\` 라이브러리에 포함되어 있으며, \`std::cout\`은 화면 출력, \`std::cin\`은 키보드 입력을 처리합니다.

    #include <iostream>
    #include <string>
    
    int main() {
        std::string name;
        std::cout << "이름을 입력하세요: ";
        std::cin >> name;
        std::cout << "안녕하세요, " << name << "님!" << std::endl;
        return 0;
    }
    

제어문 (Control Flow)
==================

코드의 실행 흐름을 조건이나 반복에 따라 제어하는 구문입니다. 프로그램이 동적으로 상황에 맞춰 동작하도록 만듭니다.

### 조건문 (\`if\`, \`switch\`)

\`if\`문은 주어진 조건의 참/거짓에 따라, \`switch\`문은 변수의 값에 따라 다른 코드 블록을 실행합니다.

    int score = 85;
    if (score >= 80) {
        std::cout << "B 학점 이상입니다." << std::endl;
    }

### 반복문 (\`for\`, \`while\`)

\`for\`문은 정해진 횟수만큼, \`while\`문은 특정 조건이 참인 동안 코드를 반복 실행합니다.

    // 0부터 4까지 5번 반복
    for (int i = 0; i < 5; i++) {
        std::cout << i << " ";
    }
    // 출력: 0 1 2 3 4
    

### 분기문 (\`break\`, \`continue\`)

\`break\`는 반복문을 즉시 탈출하고, \`continue\`는 현재 반복을 중단하고 다음 반복으로 넘어갑니다.

    for (int i = 0; i < 10; i++) {
        if (i == 3) continue; // 3은 건너뜀
        if (i == 7) break;    // 7에서 반복 중단
        std::cout << i << " ";
    }
    // 출력: 0 1 2 4 5 6
