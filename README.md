## [C++ OOP 핵심](./md/C++%20OOP%20핵심.md)  

객체 지향 프로그래밍(OOP) 패러다임

* 클래스와 객체 (Classes & Objects)
* 생성자와 소멸자 (Constructor & Destructor)
* OOP의 핵심 원리
  - 캡슐화 (Encapsulation): 정보 은닉
  - 상속 (Inheritance): 부모-자식 클래스 관계, 오버라이딩
  - 다형성 (Polymorphism): 가상 함수(`virtual`), 순수 가상 함수, 추상 클래스
