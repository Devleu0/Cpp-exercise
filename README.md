# C++ 학습 커리큘럼 로드맵 (초급부터 고급까지)

이 로드맵은 C++를 효과적으로 학습할 수 있도록 체계적인 단계를 제공합니다. 각 단계를 순서대로 따라가며 C++ 프로그래밍의 기초부터 고급 기술까지 마스터해 보세요.

---

## 1단계: C++ 기초 다지기 (초급)

이 단계에서는 프로그래밍의 가장 기본적인 개념과 C++의 문법을 익힙니다. 모든 프로그래밍의 기반이 되는 중요한 과정입니다.

### 개발 환경 설정
- 컴파일러(`GCC/G++`, `Clang`, `MSVC`) 및 IDE(`Visual Studio Code`, `Visual Studio`, `CLion`) 설치
- 첫 번째 프로그램 작성: `"Hello, World!"` 컴파일 및 실행

### 기본 문법 및 데이터 타입
- 주석, 변수, 상수 개념 이해
- 기본 데이터 타입: `int`, `char`, `float`, `double`, `bool`
- C++ 키워드 및 식별자 규칙

### 연산자
- 산술 연산자 (`+`, `-`, `*`, `/`, `%`)
- 관계 연산자 (`==`, `!=`, `>`, `<`, `>=`, `<=`)
- 논리 연산자 (`&&`, `||`, `!`)
- 증감 연산자 (`++`, `--`)
- 대입 연산자

### 입출력 스트림
- `iostream` 라이브러리
- `std::cout` (출력) 및 `std::cin` (입력) 사용법

### 제어문
- 조건문: `if`, `else if`, `else`, `switch`
- 반복문: `for`, `while`, `do-while`
- 분기문: `break`, `continue`

---

## 2단계: 핵심 프로그래밍 개념 (중급 I)

기본 문법을 넘어 프로그램을 구조화하는 데 필수적인 개념들을 학습합니다.

### 함수 (Functions)
- 함수 정의 및 호출
- 매개변수 전달 방식 (값에 의한 호출, 참조에 의한 호출)
- 반환(`return`) 값
- 함수 오버로딩
- 재귀 함수

### 배열과 문자열
- 1차원 및 다차원 배열 선언과 사용
- C-스타일 문자열 (`char` 배열)
- C++ 표준 문자열 (`std::string`)

### 포인터와 참조 (Pointers & References)
- 메모리 주소의 개념
- 포인터(`*`)와 참조(`&`)의 선언 및 사용
- `new`와 `delete`를 이용한 동적 메모리 할당
- 포인터와 배열의 관계
- `nullptr`의 이해

---

## 3단계: 객체 지향 프로그래밍 (OOP) (중급 II)

C++의 가장 큰 특징인 객체 지향 프로그래밍(OOP) 패러다임을 깊이 있게 학습합니다.

### 클래스와 객체 (Classes & Objects)
- 클래스 정의 및 객체 생성
- 멤버 변수와 멤버 함수
- 접근 지정자: `public`, `protected`, `private`

### 생성자와 소멸자 (Constructor & Destructor)
- 기본 생성자, 매개변수 있는 생성자
- 복사 생성자
- 소멸자의 역할

### OOP의 핵심 원리
- **캡슐화 (Encapsulation)**: 정보 은닉
- **상속 (Inheritance)**: 부모-자식 클래스 관계, 오버라이딩
- **다형성 (Polymorphism)**: 가상 함수(`virtual`), 순수 가상 함수, 추상 클래스

---

## 4단계: 고급 C++ 기능 (고급 I)

더 유연하고 효율적인 코드를 작성하기 위한 고급 기능들을 배웁니다.

### 템플릿 (Templates)
- **함수 템플릿**: 일반화된 함수 작성
- **클래스 템플릿**: 일반화된 클래스 작성

### 표준 템플릿 라이브러리 (STL - Standard Template Library)
- **컨테이너**: `vector`, `list`, `deque`, `map`, `set` 등
- **반복자 (Iterators)**: 컨테이너 원소 순회
- **알고리즘**: `sort`, `find`, `copy` 등

### 예외 처리 (Exception Handling)
- `try`, `catch`, `throw`를 이용한 오류 처리

### 파일 입출력
- `fstream` 라이브러리 (`ifstream`, `ofstream`)
- 파일 열기, 읽기, 쓰기, 닫기

---

## 5단계: 모던 C++ 및 실전 (고급 II)

C++11 이후 도입된 현대적인 기능들을 배우고, 실제 프로젝트에 적용하는 단계입니다.

### 모던 C++ (C++11/14/17/20...)
- **스마트 포인터**: `std::unique_ptr`, `std::shared_ptr`, `std::weak_ptr`
- **람다 표현식 (Lambda Expressions)**
- `auto` 키워드 및 타입 추론
- **범위 기반 for 루프**
- **Move Semantics (이동 의미론)**
- **동시성 프로그래밍**: `std::thread`, `std::mutex`, `std::future`

### 프로젝트 진행
- 작은 프로젝트부터 시작하여 학습한 내용 적용하기
- 예시: 콘솔 기반 게임(텍스트 RPG, 테트리스), 주소록 관리 프로그램, 간단한 라이브러리 제작

### 심화 학습
- 디자인 패턴
- 특정 분야 학습 (게임 개발: Unreal Engine, 시스템 프로그래밍, 임베디드 등)
- 빌드 시스템 (`CMake`) 및 버전 관리 (`Git`) 학습
