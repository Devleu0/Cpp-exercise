## 1. 함수 (Functions) <a name="functions"></a>

함수는 특정 작업을 수행하는 코드 블록입니다. 코드를 논리적으로 나누어 재사용성을 높이고 가독성을 향상시켜 프로그램의 구조를 체계적으로 만듭니다.

### 함수 정의 및 호출

함수 정의는 함수의 기능과 작업을 작성하는 것이고, 호출은 그 함수를 실행하는 것입니다.

```cpp
#include <iostream>

int add(int a, int b) {
    return a + b;
}

int main() {
    int result = add(5, 10);
    std::cout << "두 수의 합: " << result << std::endl;
    return 0;
}
```
```
두 수의 합: 15
```

### 매개변수 전달 방식

값 전달은 변수의 복사본을 넘겨 원본이 변하지 않으며, 참조 전달은 변수의 주소를 넘겨 원본을 변경할 수 있습니다.

```cpp
void incrementByValue(int n) { n++; }
void incrementByReference(int& n) { n++; }

int main() {
    int a = 10, b = 10;
    incrementByValue(a);
    incrementByReference(b);
    std::cout << "값 호출 후 a: " << a << std::endl;
    std::cout << "참조 호출 후 b: " << b << std::endl;
}
```
```output
값 호출 후 a: 10
참조 호출 후 b: 11
```

### 함수 오버로딩

동일한 이름이라도 매개변수 타입이나 개수가 다르면 다른 함수로 인식하여 다양한 입력 타입을 지원합니다.

```cpp
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }
```

### 재귀 함수

함수가 자기 자신을 호출하는 구조로, 복잡한 문제를 작은 문제로 나누어 해결합니다. 반드시 종료 조건이 필요합니다.

```cpp
long long factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
```
```
120
```

## 2. 배열과 문자열 <a name="arrays"></a>

배열은 동일 타입의 데이터를 순차적으로 저장하며, 문자열은 문자 배열 또는 std::string 클래스로 다룰 수 있습니다.

### 1차원 및 다차원 배열

1차원 배열은 선형 데이터 저장, 다차원 배열은 표 형태의 데이터를 저장합니다.

```cpp
int scores[5] = {100, 90, 85, 95, 80};
std::cout << scores[2];

int matrix[2][3] = { {1, 2, 3}, {4, 5, 6} };
std::cout << matrix[1][2];
```
```
85
6
```

### C-스타일 문자열 vs `std::string`

C-스타일 문자열은 char 배열이며, `std::string`은 길이 관리와 편의 기능을 제공합니다.

```cpp
#include <string>

char c_str[] = "Hello";
std::string cpp_str = "World";
std::string greeting = std::string(c_str) + " " + cpp_str;
std::cout << greeting;
```
```
Hello World
```

## 3. 포인터와 참조 <a name="pointers"></a>

포인터(type* 로 선언)는 메모리 주소를 저장하고, 참조(type&)는 변수의 별명(alias)을 만들 수 있습니다. 메모리 제어와 효율적인 데이터 처리에 중요합니다.

### 포인터와 참조

```cpp
int number = 10;
int* ptr = &number;    //&number는 number의 주소 반환
int& ref = number;
*ptr = 20;
ref = 30;    //number를 참조하는 ref를 바꾸면 number도 바뀐다.
std::cout << number;
```
```
30
```

### 동적 메모리 할당

필요한 만큼 메모리를 힙에 할당하고 해제합니다.

```cpp
int* p_arr = new int[5];
p_arr[2] = 30;
delete[] p_arr;
p_arr = nullptr;
```

### 포인터와 배열

배열 이름은 첫 요소의 주소로 동작하며, 포인터 산술로 접근 가능합니다.

```cpp
int arr[5] = {10, 20, 30, 40, 50};
int* ptr = arr;
std::cout << *(ptr + 2);
```
```
30
```

### 추가 개념 설명

* **함수 포인터**: 함수 주소를 저장, 동적 호출 가능

* **const 포인터**: 포인터 또는 값 변경 제한
  
* **스마트 포인터**: 자동 메모리 관리, 메모리 누수 방지
