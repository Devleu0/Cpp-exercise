## 1. 기본 문법 및 데이터 타입 <a name="syntax"></a>

프로그래밍의 가장 작은 단위인 문법과 데이터를 저장하는 방법을 알아봅니다. 모든 코드의 기초가 되는 중요한 개념입니다.

### 주석(Comment), 변수(Variable), 상수(Constant)

* **주석**: 코드에 대한 설명을 추가. 컴파일 시 무시됨.

  * `//` : 한 줄 주석
  * `/* ... */` : 여러 줄 주석
* **변수**: 값을 저장할 수 있는 메모리 공간, 변경 가능.
* **상수**: 값을 변경할 수 없는 변수.

```cpp
// 변수 선언 및 초기화
int userAge = 25;

// 상수 선언 (값 변경 불가)
const double PI = 3.14159;
```

### 기본 데이터 타입

| 데이터 타입   | 설명          | 예시            |
| -------- | ----------- | ------------- |
| `int`    | 정수          | `10, -100`    |
| `char`   | 단일 문자       | `'A', '5'`    |
| `double` | 실수 (소수점 포함) | `3.14159`     |
| `bool`   | 불리언 (참/거짓)  | `true, false` |

## 2. 연산자 (Operators) <a name="operators"></a>

연산자는 데이터를 계산하거나 비교하는 기호입니다. 복잡한 계산과 조건 판단에 사용됩니다.

### 산술, 관계, 논리 연산자

```cpp
int a = 10, b = 4;
// 산술 연산
int sum = a + b;    // 14
int rem = a % b;    // 2 (나머지)

// 관계 연산
bool result = (a > b); // true (1)

// 논리 연산
bool logic = (a > 5) && (b < 5); // true (1)
```

### 증감, 대입 연산자

```cpp
int x = 5;
x++;     // x = 6

int z = 10;
z += 5;  // z = z + 5, z = 15
```

## 3. 입출력 스트림 (I/O Stream) <a name="io"></a>

콘솔을 통해 사용자로부터 입력을 받고, 화면에 데이터를 출력하는 기능입니다. 프로그램과 사용자 간의 상호작용을 가능하게 합니다.

### `std::cout` 과 `std::cin`

```cpp
#include <iostream>
#include <string>

int main() {
    std::string name;
    std::cout << "이름을 입력하세요: ";
    std::cin >> name;
    std::cout << "안녕하세요, " << name << "님!" << std::endl;
    return 0;
}
```

* `std::cout` : 콘솔 출력
* `std::cin` : 콘솔 입력
* `std::endl` : 줄바꿈과 출력 버퍼 비우기

## 4. 제어문 (Control Flow) <a name="control-flow"></a>

코드의 실행 흐름을 제어하는 구문입니다. 조건이나 반복에 따라 코드 실행을 달리할 수 있습니다.

### 조건문 (`if`, `switch`)

```cpp
int score = 85;

if (score >= 90) {
    std::cout << "A 학점" << std::endl;
} else if (score >= 80) {
    std::cout << "B 학점" << std::endl;
} else {
    std::cout << "C 학점 이하" << std::endl;
}
```

### 반복문 (`for`, `while`)

```cpp
// for 반복문
for (int i = 0; i < 5; i++) {
    std::cout << i << " ";
}
// 출력: 0 1 2 3 4

// while 반복문
int j = 0;
while (j < 5) {
    std::cout << j << " ";
    j++;
}
// 출력: 0 1 2 3 4
```

### 분기문 (`break`, `continue`)

```cpp
for (int i = 0; i < 10; i++) {
    if (i == 3) continue; // 3 건너뜀
    if (i == 7) break;    // 반복 종료
    std::cout << i << " ";
}
// 출력: 0 1 2 4 5 6
```
