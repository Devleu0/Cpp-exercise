## 2. 표준 템플릿 라이브러리 (STL)

STL(Standard Template Library)은 C++의 핵심 라이브러리로, **일관성 있는 자료구조(Containers), 반복자(Iterators), 알고리즘(Algorithms)**을 제공합니다.  
STL을 활용하면 복잡한 자료구조나 알고리즘을 직접 구현하지 않고도 효율적으로 개발할 수 있습니다.  

STL의 장점은 **재사용성, 일관성, 효율성**입니다.  
컨테이너는 데이터를 구조적으로 저장하고, 반복자는 해당 데이터를 탐색하는 방법을 표준화하며, 알고리즘은 데이터 처리 방법을 추상화합니다.

---

### 2.1 STL의 3대 구성 요소

#### 2.1.1 컨테이너 (Containers)
컨테이너는 데이터를 저장하고 관리하는 자료구조입니다.  
STL에는 **순차 컨테이너(Sequence Containers)**와 **연관 컨테이너(Associative Containers)**가 있습니다.

- **순차 컨테이너:** `vector`, `list`, `deque` — 데이터가 순서대로 저장됩니다.
- **연관 컨테이너:** `set`, `map` — 키-값 쌍 또는 고유 값을 기반으로 데이터를 저장합니다.

---

#### 2.1.2 반복자 (Iterators)
반복자는 컨테이너 내부 요소를 순회하는 객체입니다.  
포인터처럼 동작하지만 컨테이너의 내부 구조를 은폐합니다.  
주요 반복자:
- `.begin()` : 첫 번째 요소를 가리킵니다.
- `.end()` : 마지막 요소 다음을 가리킵니다.
- `.rbegin()` : 역방향 순회를 시작합니다.
- `.rend()` : 역방향 순회의 끝을 나타냅니다.

---

#### 2.1.3 알고리즘 (Algorithms)
STL 알고리즘은 데이터 처리를 위한 표준화된 함수 집합입니다.  
대표적인 알고리즘: `sort`, `find`, `reverse`, `accumulate`, `max_element` 등.  
반복자를 인자로 받아 컨테이너의 데이터를 처리합니다.

---

### 2.2 컨테이너 예시

#### Vector 예시

`vector`는 동적 배열로, 크기를 자동으로 확장합니다.  
임의 접근이 가능하고 요소 삽입/삭제가 뒤쪽에서 빠릅니다.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> numbers = {30, 10, 50, 20, 40};

    // sort 알고리즘으로 정렬
    std::sort(numbers.begin(), numbers.end());

    std::cout << "정렬된 숫자: ";
    for (int num : numbers) {
        std::cout << num << " ";
    }
    std::cout << std::endl;
}
```

---

#### Map 예시

`map`은 키-값 쌍으로 데이터를 저장합니다.  
키는 고유해야 하며, 자동으로 정렬됩니다.

```cpp
#include <iostream>
#include <map>

int main() {
    std::map<std::string, int> scores;
    scores["홍길동"] = 95;
    scores["김철수"] = 87;

    for (const auto& pair : scores) {
        std::cout << pair.first << "의 점수: " << pair.second << std::endl;
    }
}
```

---

### 2.3 반복자 예시

반복자를 사용하면 컨테이너 구조에 관계없이 동일한 방식으로 요소를 순회할 수 있습니다.

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> data = {1, 2, 3, 4, 5};

    std::cout << "반복자를 이용한 출력: ";
    for (auto it = data.begin(); it != data.end(); ++it) {
        std::cout << *it << " ";
    }
    std::cout << std::endl;
}
```

---

### 2.4 알고리즘 예시

알고리즘은 반복자 범위를 인자로 받아 동작합니다.  
이로 인해 컨테이너 독립적인 코드 작성이 가능합니다.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> numbers = {5, 2, 9, 1, 5, 6};

    // 최대값 찾기
    auto max_it = std::max_element(numbers.begin(), numbers.end());
    std::cout << "최대값: " << *max_it << std::endl;

    // 역순 정렬
    std::reverse(numbers.begin(), numbers.end());
    std::cout << "역순: ";
    for (int n : numbers) {
        std::cout << n << " ";
    }
    std::cout << std::endl;
}
```

---

### 2.5 STL 활용 팁
- 가능한 STL 컨테이너와 알고리즘을 활용하면 직접 구현하는 시간과 오류를 줄일 수 있습니다.
- 알고리즘을 사용할 때는 반복자의 범위를 정확히 지정해야 합니다.
- 컨테이너 선택 시 삽입, 삭제, 접근 속도를 고려해야 합니다.
