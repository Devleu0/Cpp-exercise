## 모던 C++

### 스마트 포인터 (Smart Pointers)

스마트 포인터는 메모리 관리 자동화를 통해 메모리 누수를 방지하는 현대 C++의 핵심 도구입니다.  
주요 종류:

- `std::unique_ptr`: 단독 소유권, 이동만 가능
- `std::shared_ptr`: 참조 카운트를 기반으로 다중 소유권 지원
- `std::weak_ptr`: 순환 참조 방지를 위한 참조

**예시: `unique_ptr`**

```cpp
#include <iostream>
#include <memory>

class Resource {
public:
    Resource() { std::cout << "Resource acquired\n"; }
    ~Resource() { std::cout << "Resource destroyed\n"; }
};

int main() {
    std::unique_ptr<Resource> resPtr = std::make_unique<Resource>();
    return 0;
}
```

### 람다 표현식 & auto

람다 표현식은 이름 없는 함수를 인라인으로 정의하는 방법입니다.  
`auto`는 변수 타입을 자동으로 추론하여 코드 가독성을 높입니다.

#### 람다 표현식 예시

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

int main() {
    std::vector<int> numbers = {1, 2, 3, 4, 5, 6};
    int threshold = 3;

    auto it = std::find_if(numbers.begin(), numbers.end(),
        [threshold](int n) { return n > threshold; }
    );

    if (it != numbers.end()) {
        std::cout << "Threshold보다 큰 첫 번째 값: " << *it << std::endl;
    }
}
```

#### auto 및 범위 기반 for 루프

```cpp
#include <iostream>
#include <map>
#include <string>

int main() {
    std::map<std::string, int> scores = { {"Alice", 90}, {"Bob", 85} };

    for (const auto& pair : scores) {
        std::cout << pair.first << ": " << pair.second << std::endl;
    }
}
```

### 이동 의미론 & 동시성

#### 이동 의미론 (Move Semantics)

이동 의미론은 불필요한 데이터 복사를 피하고 객체의 리소스를 효율적으로 이동시키는 개념입니다.  
`std::move`를 사용합니다.

```cpp
#include <iostream>
#include <vector>

int main() {
    std::vector<int> vec1 = {1, 2, 3, 4};
    std::vector<int> vec2 = std::move(vec1);

    std::cout << "vec2 요소: ";
    for (int n : vec2) std::cout << n << " ";
    std::cout << std::endl;

    std::cout << "vec1 크기: " << vec1.size() << std::endl; // 0
}
```

#### 동시성 프로그래밍 (Concurrency)

멀티코어 환경에서 여러 작업을 동시에 수행하는 기법입니다.  
주요 도구:
- `std::thread`: 스레드 생성
- `std::mutex`: 데이터 동시 접근 제어
- `std::future`: 비동기 작업 결과 처리

**예시: `std::thread`**

```cpp
#include <iostream>
#include <thread>

void worker(int id) {
    std::cout << "Worker " << id << " 실행 중\n";
}

int main() {
    std::thread t1(worker, 1);
    std::thread t2(worker, 2);

    t1.join();
    t2.join();
}
```
