## 1. 함수 (Functions) <a name="functions"></a>

함수는 특정 작업을 수행하는 코드 블록입니다. 코드를 논리적으로 나누어 재사용성을 높이고 가독성을 향상시켜 프로그램의 구조를 체계적으로 만듭니다.

### 함수 정의 및 호출

함수 정의는 함수의 기능과 작업을 작성하는 것이고, 호출은 그 함수를 실행하는 것입니다.

```cpp
#include <iostream>

int add(int a, int b) {
    return a + b;
}

int main() {
    int result = add(5, 10);
    std::cout << "두 수의 합: " << result << std::endl;
    return 0;
}
```
```
두 수의 합: 15
```

### 매개변수 전달 방식

값 전달은 변수의 복사본을 넘겨 원본이 변하지 않으며, 참조 전달은 변수의 주소를 넘겨 원본을 변경할 수 있습니다.

```cpp
void incrementByValue(int n) { n++; }
void incrementByReference(int& n) { n++; }

int main() {
    int a = 10, b = 10;
    incrementByValue(a);
    incrementByReference(b);
    std::cout << "값 호출 후 a: " << a << std::endl;
    std::cout << "참조 호출 후 b: " << b << std::endl;
}
```
```output
값 호출 후 a: 10
참조 호출 후 b: 11
```

### 함수 오버로딩

동일한 이름이라도 매개변수 타입이나 개수가 다르면 다른 함수로 인식하여 다양한 입력 타입을 지원합니다.

```cpp
int add(int a, int b) { return a + b; }
double add(double a, double b) { return a + b; }
```

### 재귀 함수

함수가 자기 자신을 호출하는 구조로, 복잡한 문제를 작은 문제로 나누어 해결합니다. 반드시 종료 조건이 필요합니다.

```cpp
long long factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
```
```
120
```

## 2. 배열과 문자열 <a name="arrays"></a>

배열은 동일 타입의 데이터를 순차적으로 저장하며, 문자열은 문자 배열 또는 std::string 클래스로 다룰 수 있습니다.

### 1차원 및 다차원 배열

1차원 배열은 선형 데이터 저장, 다차원 배열은 표 형태의 데이터를 저장합니다.

```cpp
int scores[5] = {100, 90, 85, 95, 80};
std::cout << scores[2];

int matrix[2][3] = { {1, 2, 3}, {4, 5, 6} };
std::cout << matrix[1][2];
```
```
85
6
```

### C-스타일 문자열 vs `std::string`

C-스타일 문자열은 char 배열이며, `std::string`은 길이 관리와 편의 기능을 제공합니다.

```cpp
#include <string>

char c_str[] = "Hello";
std::string cpp_str = "World";
std::string greeting = std::string(c_str) + " " + cpp_str;
std::cout << greeting;
```
```
Hello World
```
### C 문자열 함수 <cstring>
| 함수                      | 설명              | 예시                          |
| ----------------------- | --------------- | --------------------------- |
| `strlen(str)`           | 문자열 길이 반환       | `strlen("Hello") == 5`      |
| `strcpy(dest, src)`     | 문자열 복사          | `strcpy(buf, "abc");`       |
| `strncpy(dest, src, n)` | 최대 n개 복사        | 버퍼 오버플로 방지용                 |
| `strcat(dest, src)`     | 문자열 이어붙이기       | `"Hello" + "World"`         |
| `strncat(dest, src, n)` | 최대 n개 붙이기       |                             |
| `strcmp(s1, s2)`        | 문자열 비교 (같으면 0)  |                             |
| `strncmp(s1, s2, n)`    | 앞 n글자 비교        |                             |
| `strchr(str, c)`        | 특정 문자 첫 위치 찾기   |                             |
| `strrchr(str, c)`       | 특정 문자 마지막 위치 찾기 |                             |
| `strstr(str, sub)`      | 부분 문자열 찾기       | `"HelloWorld"` 안의 `"World"` |


### Cpp 문자열 함수 <string>
| 함수                       | 설명           | 예시                         |
| ------------------------ | ------------ | -------------------------- |
| `size(), length()`       | 문자열 길이       | `s.size()`                 |
| `empty()`                | 비었는지 확인      | `if(s.empty())`            |
| `operator[]`             | 인덱스로 접근      | `s[0]`                     |
| `at(i)`                  | 범위 체크 포함 접근  |                            |
| `append(str)`            | 뒤에 덧붙이기      |                            |
| `operator+`              | 문자열 연결       | `"Hello" + s`              |
| `compare(str)`           | 문자열 비교       | `s.compare("abc")`         |
| `substr(pos, len)`       | 부분 문자열       | `s.substr(0, 3)`           |
| `find(str)`              | 부분 문자열 찾기    |                            |
| `rfind(str)`             | 뒤에서부터 찾기     |                            |
| `replace(pos, len, str)` | 일부 치환        |                            |
| `erase(pos, len)`        | 삭제           |                            |
| `insert(pos, str)`       | 삽입           |                            |
| `c_str()`                | C 스타일 문자열 반환 | `printf("%s", s.c_str());` |


```cpp
#include <iostream>
#include <string>
#include <cstring>
using namespace std;

int main() {
    // C 스타일 문자열
    char cstr[20];
    strcpy(cstr, "Hello");
    strcat(cstr, " World");
    cout << cstr << " (len=" << strlen(cstr) << ")\n";

    // C++ 문자열
    string str = "Hello";
    str += " World";
    cout << str << " (len=" << str.size() << ")\n";

    if (str.find("World") != string::npos)
        cout << "Found 'World'\n";

    return 0;
}

```

## 3. 포인터와 참조 <a name="pointers"></a>

포인터(type* 로 선언)는 메모리 주소를 저장하고, 참조(type&)는 변수의 별명(alias)을 만들 수 있습니다. 메모리 제어와 효율적인 데이터 처리에 중요합니다.

### 포인터와 참조

```cpp
int number = 10;
int* ptr = &number;    //&number는 number의 주소 반환
int& ref = number;
*ptr = 20;
ref = 30;    //number를 참조하는 ref를 바꾸면 number도 바뀐다.
std::cout << number;
```
```
30
```

### 동적 메모리 할당

필요한 만큼 메모리를 힙에 할당하고 해제합니다.

```cpp
int* p_arr = new int[5];
p_arr[2] = 30;
delete[] p_arr;
p_arr = nullptr;
```

### 포인터와 배열

배열 이름은 첫 요소의 주소로 동작하며, 포인터 산술로 접근 가능합니다.

```cpp
int arr[5] = {10, 20, 30, 40, 50};
int* ptr = arr;
std::cout << *(ptr + 2);
```
```
30
```

### 추가 개념 설명

* 함수 포인터: 함수 주소를 저장, 동적 호출 가능
* 람다 함수: 코드 블록을 간단히 정의 가능
* const 포인터: 포인터 또는 값 변경 제한 
* 스마트 포인터: 자동 메모리 관리, 메모리 누수 방지


### 1. 함수 포인터 (Function Pointer)

* "함수의 주소를 저장하는 포인터" → 함수를 동적으로 호출 가능.
* 보통 콜백 함수, 이벤트 처리, 동적 바인딩 등에 사용합니다.

```cpp
#include <iostream>
using namespace std;

int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

int main() {
    // 함수 포인터 선언 (int형 반환, 매개변수 2개 int)
    int (*fp)(int, int);

    fp = add;  
    cout << fp(3, 4) << endl;  // 7

    fp = sub;
    cout << fp(3, 4) << endl;  // -1
}
```

#### 특징

* 함수 이름 자체가 함수의 시작 주소 → fp = add; 가능
* 동적 실행 경로 제어에 유용 (qsort, GUI 이벤트 핸들러 등에서 많이 씀)

---

### 2. 람다 함수 (Lambda)

* 코드 블록을 함수 객체(functor) 형태로 간단히 정의하는 문법.
* 함수 포인터보다 유연하고, 지역 변수 캡처 가능.

```cpp
#include <iostream>
using namespace std;

int main() {
    auto mul = [](int a, int b) { return a * b; };
    cout << mul(3, 4) << endl; // 12

    int x = 10;
    auto addX = [x](int y) { return x + y; }; // x 캡처
    cout << addX(5) << endl; // 15
}
```

#### 특징

* 함수 이름 없이 정의 → 익명 함수
* `[ ]` 안에 캡처 규칙 (=, &, 특정 변수)
* STL 알고리즘 (std::for_each, std::sort)와 함께 자주 사용

### 3. const 포인터

C++에서 const가 붙는 위치에 따라 의미가 달라집니다.

(1) 값이 상수인 포인터 (pointer to const)
```c
const int* p = &x;  // 또는 int const* p
*p = 20;     // X 값 변경 불가
p = &y;      // ## 다른 주소 대입 가능
```

(2) 포인터 자체가 상수 (const pointer)
```c
int* const p = &x;
*p = 20;     // ## 값 변경 가능
p = &y;      // X 포인터 재할당 불가
```

(3) 값과 포인터 둘 다 상수
```c
const int* const p = &x;
*p = 20;     // X
p = &y;      // X
```

#### 요약
* const가 * 왼쪽 → 값 고정
* const가 * 오른쪽 → 포인터 고정

---

### 4. 스마트 포인터 (Smart Pointer)

* 포인터를 클래스 객체로 감싼 것. 자동으로 메모리를 관리.
* <memory> 헤더 제공.
* new/delete 대신 자동으로 메모리 해제 → 메모리 누수 방지

### 주요 종류
#### std::unique_ptr

* 소유권 독점 → 다른 포인터에 복사 불가
* 리소스가 하나의 포인터에만 종속됨
  
```cpp
#include <memory>
auto p = std::make_unique<int>(10);
// auto p2 = p; // X 복사 불가
```

#### std::shared_ptr

* 참조 카운팅 방식 → 여러 개 포인터가 같은 리소스를 공유 가능
* 마지막 소유자가 파괴될 때 delete
  
```cpp
auto p1 = std::make_shared<int>(20);
auto p2 = p1; // ## 공유 가능
```

#### std::weak_ptr

* shared_ptr와 연결되지만 참조 카운트에는 포함되지 않음
* 순환 참조(메모리 해제 안 되는 문제) 방지 용도
  
```cpp
std::weak_ptr<int> wp = p1;
```

#### 장점

* 수동 delete 필요 없음
* 예외 발생해도 메모리 누수 없음
* 안전한 객체 수명 관리
