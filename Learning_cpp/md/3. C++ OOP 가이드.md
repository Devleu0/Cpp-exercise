## 1. 클래스와 객체 <a name="classes"></a>

클래스는 객체 지향 프로그래밍(OOP)의 설계도이며, 객체는 클래스의 인스턴스입니다. 클래스는 데이터(멤버 변수) 와 기능(멤버 함수) 를 포함하여 현실 세계의 개념을 코드로 모델링합니다.  즉, 클래스는 속성과 동작을 정의하고, 객체는 이를 실제로 메모리에 생성한 실체입니다.

* - 클래스(Class): 설계도, 틀  
* - 객체(Object): 클래스로부터 생성된 실체  
* - 인스턴스(Instance): 객체가 생성된 구체적인 사례  

 객체는 같은 클래스로부터 여러 개 생성할 수 있으며, 각각 독립적인 데이터를 가집니다.

### 클래스 정의와 객체 생성

```cpp
#include <iostream>
#include <string>

class Car {
public:
    std::string color;
    int speed;

    void accelerate() { speed += 10; }
    void brake() { speed -= 10; }
};

int main() {
    Car myCar;
    myCar.color = "파란색";
    myCar.speed = 50;
    myCar.accelerate();
    std::cout << "현재 속도: " << myCar.speed << "km/h" << std::endl;
}
````

## 2. 생성자와 소멸자 <a name="constructors"></a>

생성자(Constructor)와 소멸자(Destructor)는 객체의 생명주기를 관리합니다.

* 생성자: 객체가 생성될 때 자동으로 호출되어 멤버 변수 초기화, 동적 메모리 할당, 파일 열기 등 준비 작업을 담당합니다.
* 소멸자: 객체가 소멸될 때 자동으로 호출되어 동적 메모리 해제, 파일 닫기, 네트워크 연결 종료 등 정리 작업을 담당합니다.

 생성자는 오버로딩이 가능하지만, 소멸자는 클래스당 하나만 정의할 수 있으며 `~클래스명()` 형태를 가집니다.

### 생성자

```cpp
class Person {
private:
    std::string name;
    int age;
public:
    Person(std::string p_name, int p_age) : name(p_name), age(p_age) {
        std::cout << name << " 객체 생성 완료" << std::endl;
    }
};
```

### 소멸자

```cpp
class Person {
public:
    std::string name;
    Person(std::string p_name, int p_age) : name(p_name) {}
    ~Person() {
        std::cout << name << " 객체 소멸 완료" << std::endl;
    }
};
```

## 3. OOP 핵심 원리 <a name="principles"></a>

OOP의 핵심 원리는 크게 4가지가 있습니다. (캡슐화, 상속, 다형성, 추상화)

### 캡슐화 (Encapsulation)

데이터와 기능을 하나로 묶고, 외부에서 접근하지 못하도록 보호하는 것.
주로 접근 지정자(private, protected, public) 를 사용합니다.

```cpp
class BankAccount {
private:
    double balance;
public:
    void deposit(double amount) { balance += amount; }
    double getBalance() const { return balance; }
};
```

### 상속 (Inheritance)

기존 클래스의 속성과 기능을 물려받아 새로운 클래스를 정의하는 것. 코드 재사용성과 확장성을 높여줍니다.

```cpp
class Vehicle {
public:
    void start() { std::cout << "시동 켜기" << std::endl; }
};
class Car : public Vehicle {};
```

### 다형성 (Polymorphism)

같은 인터페이스나 부모 클래스의 함수를 다양한 형태로 재정의할 수 있는 성질. 특히 `virtual` 키워드를 이용해 동적 바인딩을 구현할 수 있습니다.

```cpp
class Animal {
public:
    virtual void makeSound() { std::cout << "동물 소리" << std::endl; }
};
class Dog : public Animal {
public:
    void makeSound() override { std::cout << "멍멍" << std::endl; }
};
```

## 4. 추상화 <a name="additional"></a>

### 추상 클래스 (Abstract Class)

* 순수 가상 함수(`=0`)를 포함한 클래스. 직접 객체를 생성할 수 없으며, 반드시 상속을 통해 구체화해야 합니다.

```cpp
class Shape {
public:
    virtual void draw() = 0; // 순수 가상 함수
};
```

### 인터페이스 (Interface)

* C++에는 `interface` 키워드가 없지만, 모든 멤버 함수가 순수 가상 함수인 추상 클래스를 인터페이스처럼 사용할 수 있습니다.

```cpp
class IPrintable {
public:
    virtual void print() const = 0;
};
```

### 연산자 오버로딩 (Operator Overloading)

* 연산자의 기능을 사용자 정의 타입에 맞게 재정의하는 것.

```cpp
class Point {
public:
    int x, y;
    Point(int a, int b) : x(a), y(b) {}
    Point operator+(const Point& p) { return Point(x + p.x, y + p.y); }
};
```

### 템플릿 클래스 (Template Class)

* 자료형에 독립적인 클래스를 만들 수 있는 기능.
* 제네릭 프로그래밍(Generic Programming)을 가능하게 합니다.

```cpp
template <typename T>
class Box {
    T value;
public:
    Box(T val) : value(val) {}
    T getValue() const { return value; }
};
```

## 5. 고급 개념 <a name="advanced"></a>
### 가상 소멸자 (Virtual Destructor)

* 기반 클래스에서 소멸자를 virtual로 선언하면,
* 파생 클래스의 소멸자가 올바르게 호출되어 메모리 누수를 방지합니다.
  
```cpp
class Base {
public:
    virtual ~Base() { std::cout << "Base 소멸자 호출" << std::endl; }
};

class Derived : public Base {
public:
    ~Derived() { std::cout << "Derived 소멸자 호출" << std::endl; }
};

int main() {
    Base* obj = new Derived();
    delete obj; // Derived 소멸자 → Base 소멸자 순서로 호출됨
}
```

### 다중 상속 (Multiple Inheritance)

* 하나의 클래스가 둘 이상의 클래스로부터 상속받는 것.
* 코드 재사용성은 높지만 복잡성과 다이아몬드 문제에 주의해야 합니다.
  
```cpp
class A { public: void show() { std::cout << "A" << std::endl; } };
class B { public: void show() { std::cout << "B" << std::endl; } };
class C : public A, public B {};

int main() {
    C obj;
    obj.A::show(); // A 클래스 메서드 호출
    obj.B::show(); // B 클래스 메서드 호출
}
```

### friend 키워드

* 클래스 외부의 함수나 다른 클래스가 private/protected 멤버에 접근하도록 허용합니다. 주로 연산자 오버로딩이나 비공개 멤버 접근에 사용됩니다.
```cpp
class Box {
private:
    int value;
public:
    Box(int v) : value(v) {}
    friend void printValue(const Box& b);
};

void printValue(const Box& b) {
    std::cout << "Value: " << b.value << std::endl;
}
```

### 정적 멤버 (Static Member)

* 클래스 전체에서 공유되는 변수나 함수. 객체별로 가지지 않고 클래스 자체에 속합니다.
  
```cpp
class Counter {
public:
    static int count;
    Counter() { count++; }
};

int Counter::count = 0;

int main() {
    Counter a;
    Counter b;
    std::cout << Counter::count << std::endl; // 2
}
```
